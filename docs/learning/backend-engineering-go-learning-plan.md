# Backend Engineering with Go Learning Plan

## Career Goal

Build the Go language knowledge and practical backend engineering skills needed for a backend engineering career.

## Learning Resources

- **Ultimate Go Notebook:** Use as the affordable starting resource for Ardan's Go language material. Study language mechanics, memory, interfaces, concurrency, performance, profiling, and debugging alongside Ardan's free training code and talks.
- **Ardan Labs courses:** Upgrade to the Ultimate Go Language Guide when affordable for Bill Kennedy's complete explanations and guided teaching. The notebook remains a long-term reference.
- **Tiago Ferreira:** Follow structured, project-based backend engineering practice with Go, PostgreSQL, APIs, authentication, testing, and production workflows.
- **LedgerFlow:** Apply each concept through real implementation, mistakes, testing, and feedback. Spend at least one focused hour on the project each day.
- **Let's Go Further:** Use later as a detailed reference for production API patterns, security, database behavior, background tasks, metrics, and deployment.

## Learning Order

1. Start with the _Ultimate Go Notebook_, Ardan's free training repository, and Bill Kennedy's official talks.
2. Continue building and verifying LedgerFlow for at least one focused hour every day.
3. Buy the Ultimate Go Language Guide when affordable and use the notebook as its companion reference.
4. Subscribe to Tiago for guided backend development, projects, and feedback.
5. Study _Let's Go Further_ after gaining practical Go and PostgreSQL API experience.

Study one main resource at a time. Do not pause LedgerFlow while waiting to purchase or finish a course.

## Daily Learning Loop

1. Study one focused Go or backend concept.
2. Apply it to LedgerFlow where relevant.
3. Verify the result with a test, HTTP request, build, or database check.
4. Record questions and review mistakes before moving forward.

The courses provide structure and depth. LedgerFlow remains the main proof that the knowledge can be applied independently.
